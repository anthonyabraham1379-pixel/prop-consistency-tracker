# Release Notes

Pasted when creating each release in **Releases → [track] → Create new
release**. Max 500 characters per language. Play Console requires this
format:

```
<es-419>
...text...
</es-419>
<en-US>
...text...
</en-US>
```

This file just documents the en-US block on its own — combine it with
`../06-notas-de-version.md`'s `<es-419>` block when you paste into the
console (both live together under one "release notes" field, per
release).

## v1.0.0 — initial launch

```
<en-US>
First release of Prop Consistency Tracker:
• Create challenges with configurable rules (consistency, drawdown, profit target)
• Log your daily P&L in seconds
• Dashboard with consistency %, drawdown used and goal progress
• Calendar and history with day editing
• Performance analytics
• Multi-account: track several challenges at once
• Optional sync with your Google account
• Full English translation — switch language from Settings
</en-US>
```

## Template for future releases

```
<en-US>
• [Main new feature]
• [Improvement]
• Bug fixes and performance improvements
</en-US>
```

Tips:
- Don't mention pricing or promotions in release notes.
- Don't use release notes for results-based claims ("improves your win
  rate", etc.).
- Keep the first line informative — it's all many users ever see.
